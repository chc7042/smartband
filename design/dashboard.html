기획 노트

  • BLE 데이터 출처: Arduino의 dataCharacteristic notify → 값 0=정상 / 1=경고 / 2=위험
  • 현재 자세 카드: BLE notify 수신 시 즉시 갱신. 쿨다운(2초) 동안은 마지막 수신 값 유지
  • 오늘 요약 카운트: 앱 로컬 DB에 이벤트 저장 후 당일 집계 (히스토리 화면과 동일 데이터 소스)
  • 마지막 이벤트: 가장 최근 경고/위험 이벤트의 시각 + 종류 표시
  • 알림: BLE 값 1 또는 2 수신 시 로컬 푸시 알림 발송 (앱이 백그라운드일 때도 동작)
