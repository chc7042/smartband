기획 노트

  • 데이터 소스: BLE notify로 수신한 이벤트(값 1·2)를 앱 로컬 DB에 저장. 값 0(정상)은 로그 저장 안 함
  • 이벤트 로그: 타임스탬프 + BLE 값으로 구성 (PostureEvent 모델)
  • 당일 그래프: X축 = 시간대(1시간 단위), Y축 = 이벤트 횟수. 경고(주황)/위험(빨강) 그룹 막대
  • 주간 그래프: X축 = 요일, Y축 = 하루 합계 횟수. 경고/위험 스택 또는 그룹 막대
  • 날짜 네비게이션: ‹ › 버튼으로 이전/다음 이동. 오늘·이번 주보다 미래는 비활성화
  • 차트 라이브러리: fl_chart BarChart 위젯 사용 예정
